# pets

`/pets` 도킹 패널에 시드로 만든 아이소메트릭 모눈종이 맵을 그리고, 강아지가 그 위를 스스로 돌아다닌다. 패널에 버튼도 키도 없고, 사람이 행동을 시키는 길은 `/pets do` 하나다. 강아지는 세션 신호(프롬프트, 타이핑, 도구 호출과 그 실패, 긴 생각, 서브에이전트, 대화 압축, 턴 끝과 끝난 이유)에 반응한다.

## 실행

모든 세션에서 쓰려면 `~/.claude/settings.json` 의 `env` 에 두 값을 둔다. 폴더가 여럿이면 `;` 로 잇는다.

```json
{
  "env": {
    "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1",
    "CLAUDE_CODE_PLUGIN_DIRS": "D:/claude-mods/pets"
  }
}
```

한 세션에서만 쓰려면:

```powershell
$env:CLAUDE_CODE_ENABLE_FUNCTION_HOOKS = "1"
claude --plugin-dir "D:/claude-mods/pets"
```

## 명령

| 명령 | 하는 일 |
|---|---|
| `/pets` | 패널을 열고 닫는다. 전체 화면 레이아웃에서는 트랜스크립트 옆에 40 열 폭으로 붙는다(`columns: 40` 요청, 사람이 끈 폭이 이긴다). 아니면 프롬프트 위에 30 행으로 열린다 |
| `/pets zoom` | 보기를 맵 보기 → 원거리 → 1 배 → 2 배 → 맵 보기 순으로 바꾼다. 맵 보기·원거리는 타일을 작게 그려 같은 패널에 맵이 더 넓게 보이고(맵 보기가 가장 넓다), 2 배는 논리 픽셀 하나가 2 열 × 1 행이다. 고른 단계는 `$.store` 에 남는다(처음은 맵 보기. 맵 보기가 생기기 전에 저장한 원거리·1 배·2 배는 그대로 읽는다) |
| `/pets zoom in`, `/pets zoom out` | 한 단계씩 크게(in)·넓게(out) 본다. 2 배에서 in, 맵 보기에서 out 은 바꾸지 않고 이미 끝이라고 알린다 |
| `/pets zoom wide`, `/pets zoom far`, `/pets zoom 1`, `/pets zoom 2` | 맵 보기·원거리·1 배·2 배로 바로 바꾸고 저장한다. 이미 그 단계면 그렇다고 알린다 |
| `/pets world` | 지금 맵 세트와 고를 수 있는 세트 목록을 글로 보인다 |
| `/pets world <세트>` | 맵 세트를 바꾼다. id(`paper` `meadow` `mountain` `forest` `lake` `beach` `snow` `desert`)나 한국어 별칭(`모눈종이` `초원` `산악` `숲` `호숫가` `해변` `설원` `사막` 등)을 받는다. 고른 값은 `$.store` 의 `world` 키에 `{ v: 1, set }` 로 남는다. 모르는 이름이면 아무것도 바꾸지 않고 목록을 알린다. 그 세트의 매개변수로 맵을 새로 만들고 강아지를 새 시작 칸에 둔다(기운·들뜸·욕구와 돌고 있는 도구·턴은 이어 가고, 대기열·길·방문 기록은 버린다. 목마름은 새 맵에서 16 걸음 안에 물가가 없으면 0 이 되고, 있으면 0.1 부터 다시 오른다. 도구가 도는 중에 바꿔도 잠들지 않고, 메인 도구면 그 도구 시작에서 4 초가 지나면 기다리러 온다) |
| `/pets world auto` | 세션마다 세션 시드로 모눈종이를 뺀 세트 중 하나를 고른다. 같은 세션이면 같은 세트다 |
| `/pets pet` | 지금 동물 품종과 고를 수 있는 품종 목록을 글로 보인다 |
| `/pets pet <품종>` | 동물을 바꾼다. 강아지 품종 id(`dog` `shiba` `blackdog` `dalmatian` `brown`), 고양이 품종 id(`cat` `cheese`), 거북이·오리·펭귄 id(`turtle` `duck` `penguin`), Claude 마스코트 id(`claude`)나 한국어 별칭(`강아지` `시바` `검은강아지` `점박이` `갈색` `고양이` `치즈` `거북이` `오리` `펭귄` `클로드` `마스코트` 등)을 받는다. 지금은 한 마리만 두므로 이름을 여럿 주면 첫 번째만 쓰고 그렇게 알린다. 고른 값은 `$.store` 의 `pets` 키에 `{ v: 1, list: [id] }` 로 남는다. 모르는 이름이면 아무것도 바꾸지 않는다. 자리·행동은 그대로이고, 같은 종이면 색과 무늬만, 다른 종이면 그림·걸음·오를 수 있는 단 수·헤엄 여부도 바뀐다. 패널 제목은 패널을 여는 순간의 종 이름(강아지, 고양이, 거북이, 오리, 펭귄, Claude 마스코트)이다 |
| `/pets pet auto` | 세션마다 세션 시드로 흰 강아지를 뺀 품종(고양이·거북이·오리·펭귄·Claude 마스코트 포함) 중 하나를 고른다 |
| `/pets idle` | 잠들지 않기가 켜져 있는지 글로 보인다 |
| `/pets idle on`, `/pets idle off` | 잠들지 않기를 켜고 끈다. 켜면 신호가 없어도 잠들지 않는다(세션 신호 반응과 기운이 낮을 때의 낮잠은 그대로, `/pets do sleep` 으로 시킨 잠은 잔다). 고른 값은 `$.store` 의 `idle` 키에 `{ v: 1, on }` 으로 남는다(처음은 꺼짐. 모르는 모양·버전이면 꺼진 것으로 본다) |
| `/pets do <행동>` | 행동을 지금 시킨다: `sleep` 자기, `wake` 깨기, `sit` 앉기, `lie` 엎드리기, `play` 놀기(놀이 변형 중 하나), `ball` 공 차기, `fetch` 공 물어 오기, `zoomies` 연달아 뛰기, `roam` 멀리 가기, `explore` 둘러보기, `come` 앞으로 와서 앉기. 하던 행동과 대기열을 버리고, 자고 있었으면 눈 뜨기·기지개·몸 털기부터 한다. 할 수 있는지·대기 시간·기운은 보지 않는다. 깨어 있을 때 `wake`, 자고 있을 때 `sleep`, 공까지 길이 없을 때 `ball`·`fetch`, 걸음 수에 맞는 칸이 없을 때 `roam`(10~16 걸음)·`explore`(8~14 걸음)는 아무것도 바꾸지 않고 이유를 알린다. 패널이 닫혀 있으면 패널을 열라고 알린다. 인자 없이 쓰거나 모르는 행동이면 목록을 알린다 |

## 화면

- 셀 하나 = `▀` 한 글자 = 위아래 픽셀 2 개. 픽셀 버퍼는 `열 × 행×2` 이고, 위 픽셀이 전경·아래 픽셀이 배경이다. 위 픽셀이 비어 있으면 `▄` 로 뒤집는다(전경의 기본색은 터미널 글자색이라 비울 수 없다). 두 픽셀이 같으면 배경색 빈칸이다.
- 1 배·2 배: 타일은 12 × 6 픽셀 다이아몬드, 높이 한 단은 4 픽셀, 맵 밑판 두께는 3 픽셀이다.
- 원거리: 타일은 8 × 4 픽셀, 한 단은 3 픽셀, 밑판은 2 픽셀이고, 모눈선은 좌표가 3 의 배수인 변에만 긋는다.
- 맵 보기: 타일은 4 × 2 픽셀, 한 단은 2 픽셀, 밑판은 1 픽셀이고, 모눈선은 좌표가 6 의 배수인 변에만 긋는다. 윗면 픽셀 4 개가 모두 변에 걸린다(위 두 개는 모눈선 자리, 아래 두 개는 앞 모서리 하이라이트 자리).
- 동물은 1 배·2 배에서 원래 크기로 그린다. 원거리·맵 보기의 크기는 개발용 전환 `FAR_PET_SCALE`(`hooks/names/index.ts`)이 정한다: `'full'`(지금 값, 원래 크기), `'twoThirds'`(3 × 3 픽셀을 2 × 2 로), `'half'`(2 × 2 픽셀을 한 픽셀로). 명령·저장값이 없어 패널에서는 바꿀 수 없고, 바꾸면 `tests/frames.test.ts` 의 원거리·맵 보기 셀 해시 18 개를 다시 기록해야 한다. 줄일 때는 원래 크기로 그린 모습(입에 문 공·나뭇가지 포함)을 좌우 반전 전에 줄이고(줄인 픽셀 넓이의 절반 이상이 덮이면 칠한다. 색은 겹친 넓이로 센 가장 무거운 색이고 윤곽 픽셀은 0.45 로 센다), 줄인 뒤 반전한다. 그림자·흙과 물방울 자리·감정 표시 자리도 같은 비로 줄이고, 굴러가는 공은 절반이면 2 × 2, 2/3 이면 3 × 3 십자다. 감정 표시 그림은 원래 크기다. 시뮬레이션(걸음, 공, 효과, 카메라)은 줌과 관계없이 1 배 픽셀로 돌고, 그릴 때만 위치를 원거리·맵 보기 투영으로 옮긴다.
- 타일 크기는 패널 폭에 맞춰 바뀌지 않는다. 넓으면 더 많이 보인다.
- 최소 32 열 × 24 행. 그보다 작으면 필요한 크기를 글로 적는다. 터미널이 아닌 곳에서는 안내 글만 적는다.
- 그림체(모눈종이 세트, 기본): 흰 모눈종이. 타일 윗면은 높이 0~4 단이 `#dcdad5` `#e5e3df` `#edece8` `#f4f3f0` `#fafaf8` 로 높을수록 밝다. 선 `#c6c3c4`, 좌표가 3 의 배수인 선은 `#a29ea0`, 맵 뒤쪽 변(뒤에 칸이 없는 변)의 테는 `#8e8a8c`(흰 배경 대비 3.41). 나무는 연한 세이지색 둥근 잎(밝은 잎 `#b4c4a0` 과 잎 `#94a882` 이 대각선으로 번갈아 색연필처럼 보인다, 윤곽 `#6a7e5e`)에 회갈색 줄기 `#8a8078` 이다.
- 옆면은 왼쪽 `#c1c2c8`·오른쪽 `#a2a3ab` 이고, 한 단마다 맨 아래 줄을 왼쪽 `#b1b2b9`·오른쪽 `#92939c` 로 그어 몇 단인지 셀 수 있다(면이 아래 윗면과 맞닿는 맨 아래 줄은 긋지 않는다). 모눈종이 섬 가장자리 밑판의 맨 아래 줄은 `#8a8688`. 섬 밖은 터미널 기본색이다. 초원·산악·숲·호숫가는 끝이 없는 월드라 밑판·테가 없고 화면 전체가 지형이다.
- 옆면이 붙은 윗면 앞 모서리 한 줄은 두 단 위 윗면 색으로 밝힌다(높이 3·4 는 `#ffffff`).
- 경사 칸(아래 맵 절)의 윗면은 낮은 변이 칸 높이, 높은 변이 한 단 위인 평면이다. 방향 4 개 × 줌 3 개의 윗면 픽셀 표를 미리 만들고, 평지와 같이 픽셀 가운데가 칸 안인 픽셀만 칠해 이웃 칸과 빈틈·겹침이 없다. 윗면 픽셀 수는 1 배에서 보는 쪽으로 오르는 경사(+x·+y) 12, 멀어지며 오르는 경사(−x·−y) 60(평지 36), 원거리 4·28(평지 16), 맵 보기 0·8(평지 4)이다. 맵 보기에서 보는 쪽으로 오르는 경사는 면이 시선과 나란해 보이지 않고 옆면 삼각형만 보인다. 경사 윗면은 칸 높이의 윗면 색 한 가지로 칠하고 모눈선·앞 모서리 하이라이트·무늬를 긋지 않는다(경사 변이 셀 중간을 여러 높이로 지나 한 셀에 두 칸의 색이 함께 들어 색 쌍이 는다. 여기에 밝은·어두운 띠, 선, 하이라이트, 무늬까지 더하면 물가 프레임이 512 쌍을 넘었다). 이 칸이나 앞 이웃이 경사면 옆면은 열마다 이 칸 윗면 앞 변에서 앞 이웃 윗면 뒤 변까지 칠해, 경사 옆에는 삼각형·사다리꼴 옆면이 생긴다. 이 칸이나 앞 이웃이 경사인 옆면에는 단 줄을 긋지 않는다(경사 옆면은 한 단 반 이하다). 경사 칸의 꽃·풀포기·나뭇가지는 칸 높이(경사 낮은 변 높이)에 놓아 경사면 위 조금 아래쪽에 선다. 지표 종류가 돌인 경사는 계단이다: 같은 경사면에 오름 높이 1/3·2/3(원거리는 1/2) 자리마다 턱 줄 하나를 돌 모눈선 색으로 긋는다(맵 보기는 줄 없음). 걷기·공은 경사와 같다.
- 그늘: 빛이 왼쪽 앞에서 온다고 보고, 더 높은 NW 이웃(x − 1) 옆 윗면에는 높이 차 한 단에 칸의 절반, 두 단 이상이면 칸 전체만큼 그늘이 진다. 더 높은 NE 이웃(y − 1) 벽 밑에는 좁은 접촉 그늘이 진다. 높이 차는 두 칸이 맞닿는 변 가운데의 높이로 잰다(평지는 칸 높이, 경사는 오르는 쪽 변이 한 단 위, 반대쪽 변이 칸 높이, 옆 변이 반 단 위). 그래서 경사가 오르는 쪽의 높은 이웃은 경사에 그늘을 드리우지 않는다. 그늘과 강아지·공 그림자는 윗면 색마다 정한 더 어두운 색(`Theme` 의 `shadowOf`)으로 바꿔 칠한다. 그늘 색에도 더 어두운 색을 이어 두어 그늘 위에서도 강아지 그림자가 보인다.
- 강아지(흰 강아지, 기본): 흰 몸, 검은빛 진한 윤곽, 늘어진 갈색 귀, 빨간 목줄, 갈색 꼬리(끝은 짙은 갈색), 검은 눈(세로 2 픽셀)·코, 분홍 혀. 몸 아랫줄은 회색 그늘이다. 어떤 자세도 16 × 13 픽셀을 넘지 않는다. 발밑 윗면에 타원 그림자가 지고, 높이 뛸수록 작아진다.
- 품종은 같은 그림에 색만 다르다(`hooks/species/dog.ts`). 시바: 주황 몸, 크림색 배, 파란 목줄. 검은 강아지: 검은 몸, 밝은 눈, 빨간 목줄. 점박이: 흰 강아지에 검은 귀·꼬리, 몸 털 칸의 약 22 % 를 칸 좌표 해시로 골라 검은 점으로 바꾼다(좌우 반전 전 좌표라 돌아서도 점이 따라간다). 갈색 강아지: 모래색 몸, 갈색 귀, 초록 목줄. 고양이 품종은 고양이 그림(`hooks/species/cat.ts`)에 색만 다르다. 회색 줄무늬 고양이: 회색 몸, 짙은 회색 줄무늬, 분홍 귀 안쪽·코. 치즈 고양이: 주황 몸, 짙은 주황 줄무늬, 크림색 배. 줄무늬는 바닥 점 기준 x 가 3 의 배수인 세로 줄의 몸 털 칸이다(좌우 반전 전 좌표). 거북이·오리·펭귄은 종마다 품종 하나이고 그림은 아래 헤엄치는 종 절. 모든 품종의 윤곽은 모든 세트의 윗면 대비 3 이상이다.
- 버퍼에는 색 대신 번호를 칠한다. 번호 자리는 `hooks/pixel/palette.ts` 의 배치표 하나로 고정되어 있고(지표 종류, 세트 공통 선, 옆면 재질, 물, 소품, 효과, 동물 뱅크 묶음, 그림자 사슬 끝, 지표 종류별 무늬 그림자), 번호마다의 RGB 와 그림자 사슬은 세트 색과 품종 색으로 만든 `Theme` 가 정한다. 세트는 아래 맵 세트 표의 여덟 가지이고, 동물은 강아지 품종 다섯·고양이 품종 둘·거북이·오리·펭귄·Claude 마스코트 중 하나다(동물 뱅크 0). 감정 표시는 동물 색을 빌리지 않는 고정 색이다. 띠는 패널 번호를 쓰지 않고 자기 번호 표와 색 표로 접는다. 한 프레임에 나가는 서로 다른 (전경, 배경) 색 쌍은 512 개 이하로 둔다(Raster 는 1024 쌍까지 정확히 칠한다). `tests/palette.test.ts` 가 나무·바위·꾸밈을 켠 세트 8 개 × 시드 3 개 × 줌 4 단계 × 40 × 30·120 × 60·200 × 80 패널에서 세고, `tests/water.test.ts` 가 물이 화면에 있는 세트 4 개의 같은 줌·패널에서 센다. 끝이 없는 월드는 보이는 청크를 다 만든 온 프레임(비워 그린 칸 0)으로 센다(node 측정으로 물가 프레임은 산악 1 배 458 쌍(시드 5)이 가장 많고, 시작 자리 프레임은 동물 원래 크기 설정으로 숲 맵 보기 446 쌍(시드 42)이 가장 많다).

### 맵 세트

세트는 지형 색, 소품 색, 맵 생성 매개변수(아래 맵 절)를 함께 정한다. 모눈종이 밖의 세트는 지표 종류(풀·흙·낙엽·돌·눈·모래·젖은 모래·얼음) 몇 개를 두고, 종류마다 가장 낮은·높은 윗면 색만 적고 나머지는 규칙으로 만든다(`hooks/biome`): 윗면 색 1~3 은 0 과 4 사이를 채널마다 고르게 나누고, 윗면 그림자 = 윗면 × 0.9, 모눈선 = 가장 낮은 윗면 × 0.84, 앞 모서리 하이라이트 = 가장 높은 윗면과 흰색의 가운데. 굵은 선 = 첫 종류(산악·설원·사막은 돌, 해변은 젖은 모래)의 가장 낮은 윗면 × 0.70. 옆면 재질은 세트의 흙 옆면, 돌 `#8a867e`(사막은 `#9a6a48`. 단 줄과 함께 네 열마다 세로 줄을 긋고 단마다 두 열씩 어긋난다), 눈 `#c4ccd4` 셋이고, 오른쪽 옆면 = 왼쪽 × 0.84, 단 줄 = 그 옆면 × 0.92, 흙 = 흙 옆면 × 0.72. 모눈종이는 위 그림체 색 그대로다.

1 배에서는 윗면에 종류별 무늬를 칸 해시로 고른 변형 4 개 중 하나로 찍는다: 풀은 짙은 풀잎 점 3 픽셀, 흙은 어두운 점 2 픽셀, 낙엽은 주황 잎 점 1~3 픽셀, 돌은 금 2~3 픽셀, 눈은 흰 반짝임 1 픽셀, 얼음은 흰 반짝임 1~2 픽셀, 모래·젖은 모래는 무늬 없음. 무늬 색은 가장 낮은 윗면 × 0.8(낙엽 `#c0703a`, 눈·얼음 `#ffffff`)이고, 그늘 속에서는 무늬를 찍지 않는다. 원거리·맵 보기에서는 무늬가 없다.

물(호수·강) 칸은 수면 한 장만 그린다. 수면은 물가 윗면보다 1 픽셀 낮고, 바닥·옆면·모눈선이 없다. 얕은 물과 깊은 물은 색이 다르고, 땅과 닿은 변의 픽셀은 거품 색이다. 물가 칸은 늘 수면과 같거나 높아 물 옆에 벽이 생기지 않고, 물 쪽으로는 1 픽셀 턱만 보인다. 1 배에서는 물 칸마다 반짝임 두 픽셀이 칸 해시로 고른 자리에 찍히고, 반짝임 자리(위상)는 화면이 어차피 매 프레임 바뀌는 동안 0.6 초마다, 가만히 있을 때 1.2 초마다 옮겨 가며, 자는 동안은 멈춘다. 원거리·맵 보기에서는 반짝임이 없다. 수면에 강아지·공 그림자가 지면 얕은 물 × 0.8, 깊은 물 × 0.8 색으로 칠한다.

### 가림

타일은 `x + y` 대각선 순서로 뒤에서 앞으로 덮어 그리면서 픽셀마다 깊이 `fx + fy − dz` 를 남긴다(`dz` 는 카메라가 보는 곳의 대각선 정수. 깊이 버퍼가 Float32 라 좌표가 커져도 작은 깊이 차가 뭉개지지 않게 뺀다). 같은 화면 픽셀에 겹치는 두 점은 시선 방향(1 배에서 `(1, 1, 6)`, 원거리에서 `(1, 1, 4)`, 맵 보기에서 `(1, 1, 2)`, 높이는 그 줌의 픽셀) 만큼만 다르므로 어느 줌에서든 `fx + fy` 가 큰 쪽이 앞이다. 그다음 소품(나무·바위·꽃·풀포기·버섯·갈대·연잎·나뭇가지)을 같은 순서로 깊이와 비교해 그리고 깊이를 쓴다(장애물 소품 칸 `x + y + 0.45`, 걷는 꾸밈 `x + y + 0.6`). 강아지(`x + y + 0.4`)와 공(`x + y + 0.25`)은 그 깊이와 비교해 그려서, 앞쪽 블록과 뒤 칸 쪽에서 본 나무가 강아지를 픽셀 단위로 가리고 앞 칸의 강아지는 나무를 가린다. 가려진 윤곽 픽셀은 가린 면 위에 한 칸 걸러(`(X + Y)` 짝수 칸) `#a29ea0` 으로 비친다. 나무가 강아지 화면 상자 안에서 강아지보다 앞이면 그 상자 안 나무 픽셀을 `(X + Y)` 홀수 칸만 비워 두어, 나무 뒤 강아지는 홀수 칸에 제 색, 짝수 칸에 윤곽 비침으로 보인다(원거리·맵 보기도 같고, 상자는 줄여 그린 동물의 상자다). 소품 픽셀에는 강아지 그림자가 떨어지지 않는다. 얕은 물에 선 강아지는 발이 수면 3 픽셀 아래에 놓여, 수면 픽셀 중 강아지보다 앞인 것이 다리 아래를 가린다. 물에 뜬 헤엄치는 종은 발이 수면 6 픽셀 아래라 몸 아랫줄을 앞쪽 수면이 가린다. 동물 그림은 줌과 상관없이 같은 크기라, 물에 뜬 동물은 어느 줌에서든 그림을 수면점에서 6 픽셀 아래에 둔다(원거리·맵 보기 투영대로 두면 가라앉는 높이가 줄어 물속 줄이 수면 위로 올라온다). `tests/swim.test.ts` 가 네 줌에서 수면선 두 줄 아래로 보이는 동물 픽셀이 없는지 본다.

`tests/occlusion.test.ts` 가 세트마다 세션 대본(4~6 분마다 턴) 한 시간을 초마다 재서, 강아지 가운데 열이 7 픽셀 이상 가린 프레임이 지형만 그렸을 때 깨어 있는 시간의 1 % 이하, 소품까지 그렸을 때 깨어 있는 시간의 2 %·잠든 시간의 5 % 이하인지 본다.

### 카메라

강아지 몸통 가운데를 목표로 두되, 화면 속도 × 0.35 초만큼(최대 12 픽셀) 가는 쪽을 앞서 본다. 목표가 가운데 ±6 × ±4 픽셀 상자 안이면 움직이지 않고, 밖으로 나가면 넘은 만큼을 150 ms 지수 보간으로 따라간다. 이 픽셀 값은 1 배 기준이다. 원거리에서는 카메라 위치에 가로 8/12, 세로 4/6 을, 맵 보기에서는 가로 4/12, 세로 2/6 을 곱해 그린다. 그래서 1 배에서 카메라가 멈춰 있으면 원거리·맵 보기 화면도 멈춰 있다.

## 맵

- 시드는 세션 id 의 FNV-1a 해시다. 같은 세션이면 같은 맵이다.
- 생성기(`hooks/world/gen.ts`)는 순차 난수 없이 좌표 해시만 쓴다. 칸 값은 (시드, x, y) 의 함수라 영역을 잘라 따로 만들어도 한 번에 만든 것과 바이트가 같다. 삼각·지수 함수를 쓰지 않는다(엔진마다 마지막 비트가 다를 수 있다).
- 크기: 모눈종이는 시드로 가로·세로 각각 20~32 타일인 섬. 초원·산악·숲·호숫가·해변·설원·사막은 끝이 없는 월드다(좌표는 음수도 된다).
- 끝이 없는 월드는 32 × 32 칸 청크로 만든다(`hooks/world/chunks.ts`). 청크는 칸마다 높이·플래그·소품·지표 종류·꾸밈 1 바이트씩이다.
  - 세션 시작 때 시작 칸 청크 둘레 3 × 3 을 만들고, 패널이 붙거나 줌·세트가 바뀔 때 그 패널에 보이는 청크 중 없는 것을 그 자리에서 만든다(엔진 테스트 하네스에서 시작 직후 200 × 80 패널: 원거리 2 개 8~48 ms(호숫가·해변이 42~48 ms), 맵 보기 11 개 62~135 ms. 120 × 60 맵 보기는 5 개 29~63 ms, 40 × 30 은 0 개).
  - 그 뒤로는 틱(33 ms)마다 미리 만들 청크를 가까운 순으로 조금씩 만든다: 보이는 청크(강아지가 선 청크 포함)와 그 둘레 한 겹. 강아지 청크 둘레 한 겹이 늘 들어 길 찾기 창(±16 칸)은 늘 캐시 안이다. 한 청크는 작은 일 단위로 나뉜다(포락선 전 높이 약 128 칸, 호수 모양, 호수 수면, 영역 시작, 영역 9 행, 걷는 칸). 한 틱에 일 단위 점수 12 점까지 하고(엔진 테스트 하네스, 200 × 80 원거리 60 초에서 생성한 틱 p95 1.3~2.8 ms), 길 찾기(A*)가 돈 틱은 건너뛴다. 나눠 만들어도 결과는 한 번에 만든 것과 바이트가 같다.
  - 포락선 전 높이는 32 × 32 블록으로, 호수 결과는 호수 셀마다 캐시해 이웃 청크가 나눠 쓴다.
  - 캐시는 미리 만들 청크 수와 25 중 큰 값까지 두고(120 × 60 패널 1 배에서 25, 200 × 80 원거리에서 30, 200 × 80 맵 보기에서 48~51), 넘으면 강아지 청크에서 먼 것부터 버린다.
  - 그리기는 청크를 만들지 않는다. 아직 없는 청크의 타일은 그리지 않고(그 자리는 터미널 기본색) 다음 틱들의 미리 만들기가 만든다. 강아지·공이 없는 청크의 칸을 읽으면 그 자리에서 만든다(엔진 테스트 하네스에서 한 청크 p50 7.8~28.9 ms, p95 10.9~36 ms. 2026-09-30 지형 알고리즘 변경 전 값이고 다시 재지 않았다. 호숫가·해변은 호수가 커져 더 걸린다).
  - 멀리 두고 온 공은 멈춰 있으면 칸을 읽지 않고, 청크가 없으면 그리지 않는다.
- 지형: 도메인 워핑(초원 6 칸·산악 9 칸 등) + value noise 여러 겹(모눈종이 격자 7·3 칸)을 세트 높이 범위로 나눈다. 그 밖 세트는 바탕을 두 겹 노이즈로 몇 단에만 모은다(초원·숲 2·3·4 단(3 단이 약 60 %), 산악 1·2·3 단, 호숫가 3·4·5 단, 해변·설원 2·3 단, 사막 1·2 단). 초원·숲·설원은 그 위에 셀마다 둥근 언덕 하나를 확률로 얹는다(초원 40 칸 셀 60 %·반지름 6~11 칸, 숲 48 칸 셀 50 %·7~12 칸, 설원 36 칸 셀 55 %·5~10 칸, 높이 2~3.5 단, 가운데가 가장 높고 가장자리로 갈수록 낮아진다). 산악은 그 위에 능선 두 벌을 얹는다: 큰 줄기는 56 칸 셀마다 85 %, 길이 30~44 칸, 마루 4.5~5.5 단, 옆으로 한 칸에 0.75 단씩 내려가고, 작은 줄기는 셀을 18 칸 밀어 둔 36 칸 셀마다 55 %, 길이 14~22 칸, 마루 2.5~3.5 단, 0.9 단씩. 능선은 8 방위 중 하나로 뻗고 마루를 따라 봉우리와 두 단 낮은 고개가 번갈아 나며, 두 줄기가 겹치면 높은 쪽을 쓴다. 산악은 잔기복(간격 9 칸, 0.6 단)도 더한다. 해변은 45 도로 돌려 한 축을 4 배 늘린 능선 노이즈가 문턱을 넘는 곳에 한 방향으로 긴 사구 띠를 최대 2 단 얹는다(사구 3~4 단, 높이 상한 4 에서 잘린다). 사막은 같은 식의 노이즈(한 축 5 배)가 높은 문턱을 넘는 가는 선에 1 단 마루를 얹고, 44 칸 셀마다 55 % 로 메사(반지름 5~9 칸 안이 모두 3~5 단, 옆은 포락선이 한 칸에 한 단 계단으로 깎는다)를 세운다. 메사 자리에는 마루 선을 얹지 않는다. 호숫가·해변은 호수 셀에 호수가 있으면 그 중심 둘레(반지름 ⌈1.25 × 호수 반지름⌉ + 5 칸)를 가운데로 갈수록 깊게(호숫가 최대 3.5 단, 해변 최대 3 단) 낮춘 분지이고, 분지 바닥은 2 단이다(호숫가·해변 모두 수면 2, 깊은 물 바닥 0). 모눈종이 0~2 단, 해변 2~4 단(1 단은 호수 얕은 바닥뿐), 그 밖 세트 1~6 단. 모눈종이 섬은 가장자리에서 한 칸 들어갈 때마다 한 단까지만 올라 가장자리가 낮다.
- 포락선: 높이를 `h(p) = min_q(h0(q) + 맨해튼 거리)` 로 낮춰 블록이 아닌 이웃 칸끼리는 높이 차가 1 이하다. 높이 범위가 [바닥, hmax] 면(바닥은 hmin, 호수가 있는 세트는 깊은 물 바닥 0) 거리 hmax − 바닥 이상인 칸은 결과를 바꾸지 못해, 둘레 hmax − 바닥 − 1 칸만 더 계산하면 된다.
- 호수: 격자 셀(호숫가·해변 64 칸, 그 밖 40 칸)마다 세트 확률(초원 0.35, 산악 0.2, 숲 0.25, 호숫가 0.85, 해변 0.9, 설원 0.15, 사막 0.12)로 하나(호수 중심의 분지 전 높이가 산악·설원·사막은 2 단 이하, 초원·숲은 3 단 이하, 사막은 2 단 이하일 때만. 언덕·메사 위에는 못이 없다), 반지름(초원 3~6, 산악·숲·설원 3~5, 호숫가 9~16, 해변 10~15, 사막 3~4 칸)은 셀 해시. 해변은 끝없는 바다 대신 이 큰 호수를 둔다(끝이 있어 헤엄 못 하는 동물도 돌아간다). 초원·숲·설원·산악은 이 작은 못 말고 큰 호수 종류를 하나 더 둔다: 초원 96 칸 셀마다 0.5·반지름 8~12, 숲 96 칸 0.4·7~11, 산악 96 칸 0.45·7~11, 설원 112 칸 0.35·7~11(중심 높이 조건은 그 세트의 못과 같다). 호수 종류마다 셀 격자와 해시가 따로이고, 작은 못은 큰 호수와 발자국 상자끼리 hmax + 5 칸 안이면 두지 않아 두 호수 사이에 땅이 hmax 칸 넘게 남는다. 원점 둘레 360² 를 맵 보기 한 화면(90 × 90 칸)으로 나눈 창 중 큰 호수(물 150 칸 이상)가 든 창은 초원 44 %, 산악 36 %, 숲 33 %, 설원 23 %(시드 1~10)다. 모양은 방향 8 곳의 해시 값을 이은 반지름 × (0.75 + 0.5 × 노이즈) 안의 칸이고(각도·거리는 삼각 함수 없이 마름모 둘레 위치와 제곱 비교로), 가운데와 이어진 칸만 두고 구멍은 채운다. 수면 L 은 발자국을 hmax + 1 칸(해변 5, 그 밖 7) 넓힌 곳의 포락선 전 높이 최솟값이고 L < 1 이면 호수가 없다. 바닥은 얕은 물 L − 1, 깊은 물 L − 2(반지름 4 이상, L ≥ 2, 8 이웃이 모두 물이고 가운데에서 반지름 × 0.6 안인 칸)로 고정하고 포락선을 돌린다. 그래서 물과 닿은 땅은 수면보다 낮지 않고(떠 있는 물이 없다), 4 방향으로 닿은 물가는 수면과 같은 높이다. 경계 있는 맵에서는 발자국과 둘레 한 칸이 맵 안에 들 때만 둔다. 끝이 없는 월드의 원점 둘레 256 × 256 칸(시드 1~20) 물 비율(강 포함)은 초원 4.55 %, 산악 4.15 %, 숲 4.09 %, 호숫가 11.48 %, 해변 10.34 %, 설원 3.45 %, 사막 0.15 %(물 있는 시드 19/20)이고, 깊은 물은 초원 0.67 %, 산악 0.09 %, 숲 0.41 %, 설원 0.16 %, 사막 0.01 %, 호숫가 3.48 %, 해변 3.58 %다.
- 강: 초원·산악·숲·호숫가·설원에 있다(해변·사막은 없다). 워핑 좌표의 value noise 한 겹(간격 64 칸) n 이 |2n − 1| < 0.02 인 칸의 띠로, 폭은 대개 1~3 칸(시드 1~6 중앙값 3 칸)이고 노이즈가 0.5 근처에 오래 머무는 곳은 넓어진다. 강 칸의 포락선 전 높이를 세트 최저 단 − 1 로 박아 수면이 최저 단(1 단)인 얕은 물이다. 다른 땅은 모두 최저 단 이상이라 포락선이 강 둘레를 정확히 1 단으로 깎아 둔덕·능선을 가로지르면 골짜기가 된다(폭포·떠 있는 물이 없고 물가가 평평하다). 호수 수면을 찾는 칸 상자(발자국을 hmax + 1 칸 넓힌 곳) 안에서는 끊겨 호수 수면이 바뀌지 않는다. 띠가 가늘어지는 자리에서 끊길 수 있다. 물가 종류·장애물 둘레·갈대·연잎은 호수와 같이 다룬다.
- 장애물 후보: 3 칸 격자 셀마다 확률 `obsP × 2.2`(해변은 후보 칸이 호수 분지 안이면 2.5 배, 밖이면 0.5 배라 야자가 물가에 몰린다. 숲은 셀 위치의 노이즈(간격 24 칸)로 0.35~1.3 배라 빽빽한 곳과 빈터가 번갈아 난다) 로 후보 하나(칸 위치·종류·발자국·우선순위가 셀 해시). 종류는 나무·바위·블록을 세트 가중치로 고른다. 우선순위가 더 높은 이웃 후보와 겹치거나 8 방향으로 붙으면 버리고, 호수 발자국·강과 8 방향으로 붙어도 버린다. 장애물 덩어리끼리 대각선으로도 붙지 않고 덩어리에 구멍이 없어, 지형 칸은 모두 한 덩어리로 이어진다.
- 블록: 1×1 이 70 %, 2×1·1×2 가 30 %. 발자국 높이가 모두 같을 때만 그 위 +1 단(60 %) 또는 +2 단(40 %). 모눈종이는 최대 4 단, 그 밖 세트는 최대 8 단. 모눈종이 섬 가장자리에 걸치는 후보는 버린다.
- 나무·바위: 세트마다 나무 한 종(모눈종이 나무, 초원 활엽수, 산악 소나무, 숲 참나무, 호숫가 버드나무, 해변 야자, 설원 눈 덮인 전나무, 사막 선인장)과 바위(모눈종이는 바위 없음). 어느 종도 들어가지 못하고 공도 튕긴다. 1 배 그림은 나무 7~9 × 10~13 픽셀, 바위 7 × 5, 원거리는 나무 5~6 × 6~9, 바위 5 × 3. 맵 보기는 원거리 그림(꾸밈 포함)을 2 × 2 픽셀마다 한 픽셀로 줄여 그린다(칸에 픽셀이 하나라도 있으면 칠하고, 색은 가장 많은 색). 블록 자리는 나무를 켜든 끄든 같다(`World.create` 는 `props: true` 일 때만 나무·바위를 두고, 패널의 맵은 켠다).
- 지표 종류(순서대로 첫 참): 호수·강 칸은 물, 호수·강과 8 방향으로 닿은 칸(해변은 8 방향 거리 2 칸 안)은 물가 종류, 블록이면 돌(모눈종이는 종이), 산악의 5 단 이상에서 온도 노이즈(간격 36 칸) − 0.06 × 높이 < 0.18 이면 눈, 산악의 3 단·사막의 4 단 이상이면 돌, 습도 노이즈(간격 44 칸)가 문턱 미만이고 잔무늬 노이즈(간격 7 칸)가 문턱 초과면 얼룩(초원 흙길, 숲 낙엽, 설원 얼음. 설원 얼음은 2 단에만), 나머지는 바탕(풀, 해변·사막은 모래, 설원은 눈, 모눈종이는 종이). 칸 좌표의 함수라 영역을 잘라 만들어도 같다.
- 걷는 꾸밈: 장애물·블록이 아닌 칸에 칸 해시로 둔다. 풀 칸에 꽃(초원 6 %, 산악 3 %, 호숫가 4 %, 사막 오아시스 5 %)·풀포기(초원 9 %, 산악 4.5 %, 숲 3 %, 호숫가 6 %, 사막 오아시스 30 %), 숲의 풀·낙엽 칸에 버섯 2 %, 땅과 닿은 얕은 물에 갈대(호숫가 35 %, 해변 8 %, 사막 30 %), 호숫가의 땅과 닿지 않은 얕은 물에 연잎 12 %, 해변의 모래·젖은 모래 칸에 조개 3 %(1 배 3 × 2 픽셀), 사막의 모래 칸에 마른 덤불 2 %(1 배 5 × 3 픽셀), 다른 꾸밈이 없는 풀·낙엽·바탕 칸에 나뭇가지(초원·호숫가·해변·설원·사막 0.4 %, 산악 0.3 %, 숲 0.8 %, 모눈종이 없음, 1 배 5 × 2 픽셀, 세트 나무 줄기 색). 걸음을 막지 않고, 원거리에서는 꽃·연잎은 1 픽셀, 갈대는 2 × 3 픽셀로 그리고 나머지는 그리지 않는다. 물 위 꾸밈은 수면에 놓는다.
- 걷는 칸: 이웃과 걷는 높이(땅은 높이, 물은 수면) 차 ≤ 1 로 이어진 가장 큰 덩어리. 얕은 물은 걷고(길 비용 +0.5), 깊은 물은 헤엄치는 종(거북이·오리·펭귄)만 들어간다(길 비용 +2. 강아지·고양이는 못 들어간다). 생성기 규칙 때문에 지형 칸과 얕은 물은 모두 여기에 들고, 빠지는 것은 오를 수 없는 블록(+2 단, 둘레와 2 단 이상 차이 나는 +1 단)과 깊은 물뿐이다. 모눈종이 섬은 맵 전체 BFS 로 가장 큰 덩어리를 고르고, 끝이 없는 월드는 청크를 만들 때 칸마다 정한다(장애물·깊은 물이 아닌 지형 칸과 얕은 물은 걷는 칸, 블록 칸은 블록이 아닌 걷는 이웃과, 2 칸 블록이면 짝 칸을 거쳐, 걷는 높이 차 ≤ 1 이면 걷는 칸). 두 방법은 같은 영역에서 같은 칸을 고른다(`tests/chunks.test.ts`).
- 경사: 끝이 없는 월드에서 칸이 물·블록·나무·바위가 아니고, 네 이웃 중 걷는 높이가 더 높은 것이 정확히 하나이며 그것이 한 단 높은 땅(블록·나무·바위 아님)이고, 반대쪽 이웃이 블록·나무·바위가 아니면 그 칸은 높은 이웃 쪽으로 오르는 경사 후보다(`hooks/world/slope.ts`). 후보 중 옆(방향과 수직) 이웃 하나 이상이 같은 방향 후보인 것만 경사가 된다. 홀로 선 경사는 양옆에 삼각형 옆면이 붙어 뾰족한 모양이 되고, 등고선을 따라 그 모양이 톱니처럼 늘어서서다. 두 방향이 높은 모서리 칸은 단으로 남는다. 경사 윗면은 낮은 변이 칸 높이 h, 높은 변이 h + 1 이다. 높이·걷는 칸·오를 수 있는지는 경사가 없을 때와 같다. 방향은 청크를 조립할 때 칸 플래그 비트 5~7 에 넣고, 나무·바위는 소품 번호로 봐서 나무를 켜든 끄든 같은 자리에 생긴다. 모눈종이 섬에는 경사가 없다. 원점 둘레 256 × 256 칸(시드 1·2)에서 경사 칸은 세트마다 2.6~4.3 %, 한 단 차 이웃 쌍 중 경사로 이어진 것은 13~35 % 다(해변·사막 13~14 %, 나머지 27~35 %).
- 시작 칸: 모눈종이 섬은 가운데에서 가장 가까운 물이 아닌 걷는 칸. 끝이 없는 월드는 (0, 0) 에서 나선으로 돌며 찾은 첫 땅 걷는 칸(물·블록이 아님).
- 편집 표: 강아지가 바꾼 칸(옮긴 나뭇가지, 구덩이 흔적)은 맵이 아니라 편집 표에 두고 칸 질의가 먼저 본다. 편집이 가리키는 칸이 물(강·호수)이나 나무·바위 칸이면(생성기가 바뀌어 예전 저장값의 땅이 물이 된 경우) 읽을 때 적용하지 않고, 편집 표와 저장값에서는 지우지 않는다. 청크를 버렸다 다시 만들어도 남는다. 256 칸까지이고 넘으면 구덩이만 있는 칸을 오래된 것부터 버린다(그래도 없으면 나뭇가지는 집어 든 칸으로 되돌린다). 구덩이 흔적은 30 분(실제 시각) 뒤 사라지고, 윗면 가운데 4 × 2 픽셀(원거리 2 × 1, 맵 보기는 그리지 않는다)을 흙 × 0.7 색으로 칠한다(그림자는 흙 × 0.55).
- 편집 저장: `$.store` 의 `edits:<세트>:<세션 시드 16 진 8 자>` 키에 `{ v: 1, at, list: [x, y, 종류, 값][] }`(종류 1 꾸밈 덮기, 2 구덩이). 바뀌었으면 60 초에 한 번과 세션 끝에 쓰고, 세트를 바꿀 때 옛 세트 것을 쓰고 새 세트 것을 읽는다. 지금 키의 값이 모르는 버전·모양이면 빈 표로 쓰고 그 키에는 쓰지도 지우지도 않는다. 세션을 시작할 때 다른 세션의 편집 키는 가장 최근 것 7 개만 남긴다(모르는 버전·모양의 값은 세지도 지우지도 않는다).
- 공 하나가 시작 자리 근처 걷는 칸(경사 칸 아님)에 놓인다. 공은 깊은 물에서 튕기고, 얕은 물에서는 수면 1 픽셀 아래에 떠서 마찰이 크다(초당 6 타일/초, 땅 2.4). 높이는 걷는 높이로 비교해 물에 뜬 공도 같은 높이의 물가로 굴러 나온다. 경사 칸에서는 바닥이 선 자리의 경사면이고 내리막 쪽으로 4.8 타일/초² 로 가속해(마찰보다 커서 멈춘 공도 굴러간다) 경사 아래 평지까지 내려가 멈춘다. 경사 아래 끝 칸은 늘 들어갈 수 있는 칸이다. 굴러가다 바닥이 2.5 픽셀 이하로 낮아지면 떨어지지 않고 바닥에 붙는다.

## 강아지

### 평소 행동

행동이 끝나면 평소 행동마다 점수를 매겨, 점수에 비례한 난수로 다음 행동을 고른다. 가장 높은 점수를 고르지 않으므로 같은 상태에서도 행동이 갈린다.

점수 = 기본 가중치 × 할 수 있는지(0 또는 1) × 대기 시간이 지났는지(0 또는 1) × 반복 벌점 × 기운·들뜸·바쁨 배율 × 욕구 항

- 반복 벌점: 최근 평소 행동 6 개 중 같은 행동이 있는 자리마다 0.65, 0.30, 0.15, 0.08, 0.04, 0.02 를 더해 1 에서 뺀 값(최소 0.1). 신호로 끊긴 평소 행동도 한 것으로 치고, 신호가 부른 행동(인사, 도구·턴 끝 반응, 잠 등)과 `/pets do` 로 시킨 행동은 치지 않는다.
- 욕구 항: 0.35 + Σ 욕구 계수 × 욕구, 최대 3. 욕구는 호기심·놀고 싶음·사람 곁·목마름(0~1)과 쉬고 싶음(1 − 기운).

- 기운이 0.12 이하면 뽑기 전에 낮잠을 고른다. 모든 점수가 0 이면 가만히 선다.
- 목적지가 핵심인 행동(탐험·멀리 가기·순찰·높은 곳·지켜보기·낮잠·마시기·물장난·씹기·땅 파기·헤엄)은 길이 없으면 그 행동을 그만두고 30 초 동안 다시 고르지 않는다.

- 글이 흐르는 중(응답이 시작될 때와 텍스트·생각·도구 인자 조각 16 개마다 2.5 초씩 연장): walk × 1.5, sniff × 1.6, sit × 0.5, lie × 0.3
- 메인 턴이 90 초 넘게 이어지는 중: sit × 0.8, lie × 0.8
- 기운(energy, 0~1): run 은 0.4 아래에서 × 0.2, play × (0.3 + 기운)
- 들뜸(excite, 0~1): run × (1 + 2 × 들뜸), play × (1 + 들뜸)

욕구(초당, 0~1 로 자른다. 처음 호기심 0.4, 놀고 싶음 0.3, 사람 곁 0.3):

- 호기심: +0.005. 킁킁대는 동안 −0.01. 걷기·탐험·멀리 가기·순찰·높은 곳 중 2 분 넘게 안 간 칸에 들어설 때마다 −0.01
- 놀고 싶음: +0.003 + 0.006 × 들뜸. 놀이·달리기·뒹굴기·물장난 중 −0.015. 공을 찰 때마다 −0.05
- 사람 곁: 프롬프트·타이핑이 30 초 넘게 없으면 +0.004, 있으면 −0.01. 지켜보기로 앉아 있는 동안 −0.06 더. 프롬프트 때 −0.3, 타이핑 반응이 나올 때(4 초에 한 번까지, 자는 중 z 를 건너뛸 때도) −0.03
- 목마름: +0.0015, 속보·달리기 중 +0.006 더, 마시는 동안 −0.15. 행동을 고를 때마다 16 걸음 안에 물가가 있는지 다시 보고, 없으면 0 에 묶어 두며(물 없는 맵에서는 늘 0), 처음 가까워지면 0.1 부터 오른다

기운은 달리기 초당 −0.025, 속보 −0.01, 걷기 −0.004, 살금 걸음 −0.003, 파기·몸 낮춤 −0.01 로 줄고, 앉기 +0.006, 엎드리기 +0.012, 졸기 +0.016, 잠 +0.03 으로 찬다. 들뜸은 신호마다 오르고(프롬프트 +0.45, 턴 끝 +0.15) 40 초 시상수로 식는다.

### 세션 신호

세션 신호가 지금 행동에 하는 일은 지금 행동의 부류(평소, 잠, 가벼운 반응, 도구 반응, 권한 대기, 턴 끝 반응, 인사와 `/pets do` 로 시킨 행동)마다 정해져 있다: 끊고 시작하기, 대기열 앞·뒤에 넣기, 하던 자세 늘리기, 하던 행동을 대기열 앞에 되돌려 놓고 끊기, 버리기, 얼굴만 잠깐 돌리기. 대기열은 3 개까지이고 넘치면 뒤쪽의 가벼운 반응부터 버린다. 잠자리로 걸어가는 중(아직 잠들지 않음)은 평소 행동으로 친다.

| 신호 | 강아지 |
|---|---|
| 프롬프트(`turn.start`) | 무엇을 하든 끊고 대기열을 비운다. 사람 쪽을 보며 `!`, 40 자 미만 프롬프트면 3~6 걸음 속보, 그보다 길면 5~12 걸음 달려가 헥헥. 글이 빈 턴(이어 하기)이면 달려가지 않고 사람 쪽만 본다. 자고 있었으면 먼저 눈 뜨기, 기지개(인사면 몸 털기까지) |
| 타이핑(`prompt.edit`) | 평소 행동 중이면 0.8~1.4 초 사람 쪽을 보고, 40 % 는 이어서 0.7 초 고개를 갸웃한다(4 초에 한 번까지). 자고 있으면 다음 `z` 하나만 건너뛴다. 그 밖에는 버린다 |
| 턴 도중 입력한 프롬프트(`prompt.submit`) | 평소 행동 중이면 사람 쪽을 보며 `!` |
| 긴 생각(`turn.step` 의 생각 조각, 메인 루프만) | 글·도구 조각 없이 생각 조각이 3 초 넘게 이어지면 평소 행동을 끊고 왼쪽 위를 보고 앉아 2.5 초마다 말줄임표를 띄운다(최대 20 초). 첫 글·도구 조각에서 멈춘다 |
| 메인 도구 호출(`tool.call`) | 도구 이름으로 반응을 고른다. 읽기·찾기(Read, Grep, Glob, ToolSearch, TaskOutput, ListAgents)는 한 걸음 안에서 0.8~1.4 초 코를 박는다. 바깥(WebFetch, WebSearch, `mcp__` 로 시작하는 도구)은 오른쪽 위를 보고 1.2~2 초 귀를 세웠다가 한두 칸 속보. 그 밖(고치기, 명령, 이름 모름)은 그 자리에서 `?` 를 띄우고 1.3~1.9 초 앞발로 판다(흙이 뒤로 튄다), 이어서 0.6 초 킁킁. 도구 반응 중에 또 오면 새로 시작하지 않고 그 자세를 0.9 초씩 늘린다(최대 4 초). 인사 중이면 대기열 맨 앞에 넣어 도착한 뒤에 하고, 턴 끝 반응 중이면 그 남은 부분을 대기열 앞에 되돌려 놓고 반응한다. 반응은 토큰 2 개 통(1.5 초에 하나 참)을 거친다. 자는 중이면 반응하지 않는다 |
| 오래 도는 메인 도구 | 4 초 넘게 돌면 평소 행동을 끊고 앞쪽 1~3 걸음의 물이 아닌 칸에 와서 사람 쪽을 보고 앉아 기다린다. 도구가 끝나면 멈춘다. 마시는 중이면 다 마신 뒤에 온다 |
| 서브에이전트 도구 호출(`tool.call` 의 `agentId`) | 평소 행동 중이고 멈춰 있을 때만 얼굴을 오른쪽 위로 0.4 초 돌렸다가 되돌린다(4 초에 한 번까지). 행동은 바꾸지 않는다 |
| 도구 실패(메인 도구 결과의 `isError`, `deny`) | 오류면 귀를 세우고 입을 0.15 초씩 두 번 벌리며 짖는 표시를 띄우고, 거부면 정면으로 앉아 있다가 고개를 갸웃하며 `?`. 20 초 안의 두 번째 실패면 귀를 처뜨리고 엎드려 있다가 기지개를 켠다. 인사 중이면 도착한 뒤에, 턴 끝 반응 중이면 버린다(3 초에 한 번까지) |
| 서브에이전트 시작(`agent.spawn`) · 끝(서브에이전트의 `turn.complete`) | 평소 행동 중일 때만: 시작이면 오른쪽 위를 보다가 사람 쪽을 보며 음표, 끝이면 0.5 초 사람 쪽을 보며 음표 |
| 대화 압축(`session.compact`, 사람이 부른 것과 자동) | 몸을 털고 기지개. 평소 행동이면 끊고, 반응 중이면 그 뒤에 한다. 오래된 방문 기록 절반을 잊는다 |
| 턴 끝(`turn.complete`, 메인 루프만) | 끝난 이유에 따라: 답함은 1~3 걸음 떨어진 물이 아닌 칸으로 걸어가 정면으로 앉아 하트를 띄우고 5~9 초 꼬리를 흔든다(2 분 넘은 턴이면 먼저 기지개, 몸 털기). 중단은 제자리에서 솟았다가 `!`, 오류는 귀를 처뜨리고 엎드려 있다가 기지개, 거절은 정면으로 앉아 있다가 고개를 갸웃하며 `?`. 도구 반응·인사 중이면 그 뒤에 한다 |
| 3 분 동안 신호 없음 | 6 걸음 안에서 뒤쪽(화면 위쪽) 이웃이 높은 자리(물 칸, 앞쪽 두 대각선 안에 나무가 있는 칸은 뺀다)로 걸어가 하품, 제자리를 한 바퀴 반 돌고 엎드렸다가 웅크려 잔다. 숨에 맞춰 등이 오르내리고 1.7 초마다 `z` 가 떠오른다. 잠든 지 1 분이 지나고 기운이 가득 차면 스스로 깨어 눈 뜨기(0.7 초), 기지개(0.9 초), 몸 털기(0.5 초)를 하고 평소 행동으로 돌아간다. 깨면 신호 없는 시간을 새로 재므로, 신호가 없으면 깨어 3 분, 잠 1 분이 되풀이된다. 프롬프트가 오면 1 분이 안 됐어도 깬다. 잠들지 않기(`/pets idle on`)가 켜져 있으면 잠들지 않는다 |

도구가 실행 중인 동안은(서브에이전트 도구 포함) 신호가 이어지는 것으로 본다(긴 명령을 기다리는 동안 잠들지 않는다). `/pets` 로 패널을 여는 것도 신호로 친다. 패널이 닫혀 있으면 신호 시각만 적고 행동은 바꾸지 않으며, 시뮬레이션도 멈춰 있다. 타이핑과 턴 도중 입력은 키 입력을 늦추지 않으려고 시계를 읽지 않고 마지막 프레임 시각을 쓰므로, 패널이 닫혀 있으면 아무것도 하지 않는다.

권한 대화상자 대기(앞쪽에서 정면으로 앉아 앞발을 들고 조르다가 90 초 뒤 엎드려 기다림)는 행동 모듈에만 있고 신호를 연결하지 않았다. 그 대기를 알리는 이벤트가 함수 훅에 오는지 아직 확인하지 못했다.


### 움직임

- 시뮬레이션은 1/60 초 고정 스텝으로 돈다. 프레임 사이 시간(최대 1 초)을 잘라 돌리므로 패널을 다시 열어도 목적지나 뛰는 호를 지나치지 않는다.
- 길: A*(이웃 4 방향, 걷는 높이 차 ≤ 1, 뛰어야 하는 단차 한 번에 비용 +0.4(경사를 따라 걷는 걸음은 뛰지 않아 +0 이라 되도록 경사로 돈다), 얕은 물로 들어가는 걸음 +0.5 라 되도록 평지·땅으로 돈다). 길 찾기와 걸음 수 BFS 는 출발 칸 ±16 칸 안에서만 한다. 목적지가 12 걸음 안이라 단차 비용을 넣어도 최적 경로가 이 안에 들고, 결과는 맵 전체를 찾은 것과 같다. 장애물 소품 칸(나무·바위)은 걷는 칸이 아니고 공도 거기서 튕긴다.
- 속도(타일/초): 걷기 2.4, 속보 3.6, 달리기 6.0, 킁킁 1.1. 가속·감속 한도 안에서 목표 속도로 다가가고, 끝 칸에 가까우면 `√(2 × 감속 × 남은 거리)` 로 줄여 미끄러지지 않고 선다.
- 꺾는 칸은 가운데 0.22 타일 앞에서 다음 칸으로 넘어가 모서리를 둥글게 돈다(세 칸 높이가 같고 경사 칸이 없을 때만).
- 발 높이는 선 자리의 윗면 높이다. 경사 칸에서는 낮은 변에서 높은 변까지 한 단을 고르게 오른다.
- 단차: 다음 칸과 맞닿는 변 가운데의 높이 차가 한 단 이상이고(평지끼리는 걷는 높이 차, 경사를 따라서는 0, 경사 옆 변은 반 단이 섞인다) 그 칸이 0.62 타일 안이면 걷던 중에는 80 ms 웅크렸다가, 달리던 중에는 바로 포물선으로 뛴다(오를 때 5 픽셀, 내릴 때 3 픽셀, 달리면 +2). 착지하면 90 ms 몸이 한 픽셀 눌리고 먼지가 인다. 경사를 따라 오르내릴 때는 변 높이가 같아 뛰지 않고, 경사 옆 변에서 같은 높이 칸으로 건너면 발이 반 단(2 픽셀) 옮겨진다. 물가와 얕은 물은 걷는 높이가 같아 뛰지 않고 걸어 들어가며, 물속에서는 발이 수면 3 픽셀 아래에 놓인다(헤엄치는 종은 아래 절).
- 걸음 위상은 시간이 아니라 걸은 거리 ÷ 보폭(걷기 0.62, 속보 0.9, 달리기 1.3, 킁킁 0.45 타일)으로 돈다. 그래서 속도가 바뀌어도 발이 바닥에서 미끄러지지 않는다.
- 다리는 매 프레임 두 픽셀 폭 선으로 그린다(가까운 다리는 뒤쪽 윤곽 + 앞쪽 흰 털, 먼 다리는 짙은 회색 + 옅은 회색). 다리마다 위상의 앞 σ 동안 발이 바닥을 짚고 뒤로 밀리고, 나머지 동안 들려서 앞으로 돌아온다. 걷기는 네 박자(σ 0.7), 속보는 대각 짝(σ 0.5), 달리기는 앞·뒤 짝이 모이고 벌어지며(σ 0.38, 발끝 ±2) 네 발이 다 뜬 순간 몸이 한 픽셀 솟는다.
- 좌우가 뒤집힐 때 110 ms 정면 모습을 보인다.
- 꼬리는 자세마다 기본 각·폭·빠르기가 다르다(달리기는 뒤로 눕히고, 킁킁·몸 낮춤은 높이 빠르게, 들떠 있으면 서 있을 때도 빠르게 흔든다). 눈은 1.8~5.2 초마다(20 % 는 두 번 연달아) 130 ms 감는다.

### 고양이

고양이는 위 행동·신호·움직임 규칙을 그대로 쓰고, 종 정의(`hooks/species/cat.ts`)의 값만 다르다.

- 그림: 서 있을 때 몸통 7 픽셀, 뾰족한 귀 둘과 분홍 코의 머리 7 픽셀, 꼬리 4 픽셀(꼬리 색 선, 끝은 윤곽). 목줄이 없다. 엎드리기는 앞발을 몸 밑에 넣은 식빵 자세이고, 웅크려 잘 때는 꼬리로 몸 앞을 감싼다. 새 그림은 서기·옆머리·뒷머리·앉기·엎드리기·잠 두 장·정면 앉기·정면 서기 9 장이다.
- 강아지 전용 그림을 쓰는 자세는 고양이 자세로 바꿔서 한다: 뒹굴기 → 엎드리기, 갸웃 → 정면 앉기, 귀 세움 → 서기, 조르기 → 정면 앉기, 풀 죽기 → 엎드리기. 도구 호출에 반응해 파는 대신 앉아 눈을 감고 고개를 숙였다 들며 앞발을 핥는다(흙이 튀지 않는다). 자세를 시작할 때 바꾸므로 효과·기운 변화도 바꾼 자세를 따른다. 마시기·씹기는 강아지와 같이 한다. 짖기 반응의 짖는 표시는 그대로 뜬다.
- 평소 행동 가중치 배율: walk × 0.8, idle × 1.3, sniff × 0.6, sit × 1.5, run × 0.5, lie × 1.8. 뒹굴기와 평소 땅 파기(digSpot)는 하지 않는다.
- 속도(타일/초): 걷기 2.0, 속보 3.2, 달리기 6.5, 킁킁 0.9, 살금 0.8. 보폭 0.55·0.85·1.4·0.4·0.4 타일. 달리기 σ 0.35.
- 오르기: 걷는 높이 차 2 까지 한 걸음에 오르내린다(길 찾기도 차 ≤ 2). 단차 호는 오를 때 7 픽셀, 두 단을 한 번에 오르면 11 픽셀, 내릴 때 3 픽셀, 달리면 +2. 웅크림 120 ms. 폴짝은 9 픽셀·420 ms. 달릴 때 먼지가 일지 않는다. 나무·바위 칸에는 강아지처럼 들어가지 못한다.
- 걷는 칸: 강아지는 맵의 걷는 칸(가장 큰 덩어리)을 쓰고, 고양이는 장애물 소품·깊은 물이 아닌 칸을 모두 걷는 칸으로 보고 닿을 수 있는지는 길 찾기로 가린다. 그래서 고양이는 강아지가 못 오르는 +2 단 블록 위에도 올라간다.

### 헤엄치는 종(거북이·오리·펭귄)

세 종은 위 행동·신호·움직임 규칙을 그대로 쓰고, 종 정의(`hooks/species/turtle.ts` `duck.ts` `penguin.ts`)의 값만 다르다. 셋 다 깊은 물을 건너고, 물 칸(얕은 물 포함)에 들어가면 헤엄친다.

- 헤엄: 물 칸에 있는 동안 행동이 고른 걸음 대신 종의 헤엄 걸음으로 움직이고(거북이 1.2, 오리 1.6, 펭귄 3.0 타일/초), 어떤 자세든 물에 뜬 몸 그림으로 그린다(다리 없음, 헤엄치면 젓는 박자로, 가만히 있으면 0.7 초마다 한 픽셀 오르내린다. 잠·졸기 자세면 눈을 감는다). 발은 수면 6 픽셀 아래이고, 물에 들고 날 때 발 높이를 초당 24 픽셀로 옮겨 서서히 잠기고 떠오른다. 쉬러 가는 자리(잠자리·자리잡기·앞쪽 칸)는 강아지처럼 물 칸을 뺀다.
- 몸 앞을 숙이는 자세(인사, 기지개)는 다리가 한 픽셀이라 몸이 땅에 묻혀 서기로 바꾼다. 살금 걸음과 착지 눌림도 몸을 낮추지 않는다.
- 거북이: 등딱지 9 × 5 픽셀(초록 등딱지에 짙은 무늬, 연두 가장자리), 피부색 머리(옆머리 4 × 3, 뒷모습은 목 한 픽셀), 한 픽셀 길이 네 다리(대각 짝, σ 0.8). 꼬리는 그리지 않는다. 앉기·엎드리기는 다리를 넣고 등딱지를 땅에 붙인 모습, 잠은 머리·다리를 넣고 껍질에 숨은 모습이다. 속도 걷기 0.5, 속보 0.7, 달리기 0.9, 킁킁 0.35. 단차 호 2 픽셀, 웅크림 400 ms. 손으로 찍은 그림은 등딱지·옆머리·뒷모습 목·잠 두 장·정면·헤엄 7 장이다(정면 앉기·서기는 같은 그림, 앉기·엎드리기는 등딱지를 한 픽셀 낮춘 것). 평소 행동 배율: walk × 1.2, idle × 1.5, play × 0.2, lie × 1.5, sit·run·뒹굴기·땅 파기는 하지 않는다. 도구 호출에는 파는 대신 코를 박는다(킁킁). 없는 자세: 뒹굴기·풀 죽기 → 엎드리기, 갸웃·조르기 → 정면 앉기, 귀 세움 → 서기, 귀 긁기·핥기 → 킁킁.
- 오리(흰 오리): 흰 몸, 주황 부리·발, 날개 선, 들린 꼬리. 머리가 몸 그림에 들어 있어 뒷모습은 몸 그림의 눈을 털로 바꿔 만든다. 두 발은 한 픽셀 폭 주황 선이고, 걸을 때 반 주기마다 몸이 한 픽셀 앞으로 나갔다 돌아온다(뒤뚱). 킁킁·마시기처럼 머리를 3 픽셀 넘게 내리는 모습은 고개를 숙여 부리를 땅에 댄 그림으로 그린다. 속도 걷기 1.4, 속보 2.0, 달리기 3.0, 킁킁 0.6. 손으로 찍은 그림은 서기·잠 두 장·정면·고개 숙임 5 장이다(헤엄은 서기 그림 아래에 물속 두 줄을 더한 것, 앉기·엎드리기는 서기를 한 픽셀 낮춰 발을 가린 것). 평소 행동 배율: walk × 1.2, sniff × 1.5, play × 0.5, sit × 1.2, run × 0.5, 뒹굴기·땅 파기는 하지 않는다. 도구 호출에는 파는 대신 킁킁대고, 귀 긁기 대신 앉아 깃을 고른다(핥기).
- 펭귄: 검은 등·머리, 흰 배와 얼굴 옆, 흰 눈 테, 주황 부리·발. 오리처럼 머리가 몸 그림에 들어 있고 뒤뚱 걷는다. 달리기는 배를 땅에 대고 미끄러진다(엎드린 몸, 다리 없음, 초당 3.5 타일). 속도 걷기 0.9, 속보 1.4, 킁킁 0.5. 선 채로 눈을 감고 잔다. 손으로 찍은 그림은 서기·엎드리기(미끄럼)·숨 내쉰 잠·정면·고개 숙임 5 장이다(숨 들이쉰 잠은 서기의 눈을 감긴 것, 헤엄은 엎드리기 아래에 물속 한 줄을 더한 것, 앉기는 서기와 같다). 평소 행동 배율: walk × 1.2, idle × 1.3, sniff × 0.5, run × 0.6, lie × 1.2, sit·뒹굴기·땅 파기는 하지 않는다. 도구 호출에는 파는 대신 깃을 고른다(핥기).
- 공놀이는 강아지처럼 입(부리)에 문다. 감정 표시(짖는 표시 포함)는 그대로 뜬다. 띠는 늘 꺼져 있고 강아지 띠 그림에 품종 띠 색을 입힌다.

### Claude 마스코트

위 행동·신호·움직임 규칙을 그대로 쓰고, 종 정의(`hooks/species/claude.ts`)의 값만 다르다. 헤엄치지 못하고(강아지·고양이처럼 깊은 물에 들어가지 않는다) 한 단씩 오른다.

- 모습: 주황 몸통(`#d97757`, 짙은 갈색 윤곽) 10 × 6 픽셀에 검은 네모 눈 둘, 양옆으로 한 픽셀 팔, 아래로 한 픽셀 폭 두 픽셀 길이 다리 넷(대각 짝, 서로 떨어져 있다). 머리가 몸 그림에 들어 있어 뒷모습은 눈을 몸 색으로 바꿔 만든다. 오른쪽을 볼 때 눈이 몸 가운데에서 반 픽셀 앞으로, 정면(사람을 볼 때)은 가운데에 있다. 손으로 찍은 그림은 서기·고개 숙임·정면 3 장이고, 앉기·엎드리기는 서기를 두 픽셀 낮춰 다리를 가린 것, 잠은 그 모습에서 눈을 감고 숨 내쉴 때 윗줄이 내려앉는 것이다.
- 공은 앞쪽 팔 끝에 든다. 입이 없어 헥헥대거나 마실 때 혀는 몸 색으로 칠한다.
- 속도 걷기 1.8, 속보 2.8, 달리기 4.5, 킁킁 0.8 타일/초. 단차 호 오를 때 4 픽셀, 내릴 때 3 픽셀. 평소 행동 배율은 강아지와 같고 뒹굴기·땅 파기는 하지 않는다. 도구 호출에는 파는 대신 킁킁댄다. 없는 자세: 뒹굴기·풀 죽기 → 엎드리기, 갸웃·조르기 → 정면 앉기, 귀 세움·인사·기지개 → 서기, 귀 긁기 → 핥기.

### 그리기 간격

타이머는 하나다. 패널이 열려 있으면 33 ms 마다 시뮬레이션을 돌리고, 그리기는 걷기·뛰기, 먼지·흙 같은 효과, 감정 표시, 카메라 이동, 공 굴림, 파기·털기·긁기·헥헥·제자리 돌기 중에는 매 틱, 가만히 서 있거나 앉아 있으면 66 ms, 자는 중이면(떠오르는 `z` 가 있어도) 150 ms 마다 한다. 셀이 바뀌었을 때만 `$.ui.blit` 한다.

## 개발

```powershell
claude plugin test "D:/claude-mods/pets"
claude plugin validate "D:/claude-mods/pets"
```

`hooks/` 아래 `register.ts` 와 `view/` 를 뺀 모듈은 `$` 를 쓰지 않는 순수 모듈이다.

| 폴더 | 내용 |
|---|---|
| `names` | 상수(패널 크기, 타일 크기, 맵 크기, 프레임 간격, 잠들기까지 시간) |
| `rng` | 시드 난수(mulberry32), 가중치 무작위, 문자열 해시 |
| `world` | 좌표 해시 생성기(`gen.ts`: 높이 노이즈와 세트별 지형(바탕 단 수·스탬프·능선 띠·호수 분지), 호수, 강, 포락선, 장애물 후보, 지표 종류, 걷는 꾸밈, 나눠 만드는 영역), 경계 있는 섬 만들기, 끝이 없는 월드의 청크 저장소(`chunks.ts`: 포락선 전 높이·호수 캐시, 일 단위로 나눠 만들기, 캐시 버리기), 편집 표와 저장 모양, 경사 칸 배치(`slope.ts`), 칸 높이·플래그(걷는 칸·물·깊은 물·장애물 소품·블록·경사 방향)·소품 번호·지표 종류·꾸밈, 이동 규칙(오를 수 있는 단 수, 헤엄), 칸 질의 함수(걷는 높이, 발 높이, 경사 윗면 높이, 칸의 겉, 물가 목록 등) |
| `path` | 출발 칸 ±16 칸 창 안의 A* 와 BFS 걸음 수 |
| `pixel` | 팔레트, 픽셀·깊이 버퍼, `▀`·`▄` 접기, 그림을 1/2·2/3 로 줄이기(`shrink`), 셀 인코딩(auto-tetris 의 grid 와 같은 base64) |
| `iso` | 투영, 타일 그리기(지표 종류별 윗면 색·무늬, 재질별 옆면, 경사 윗면·계단 줄, 수면·거품·반짝임)와 컬링, 그림자, 카메라 |
| `prop` | 나무·바위·꾸밈·나뭇가지 도트(`art.ts`, 1 배·원거리 두 벌과 세트별 색. 맵 보기 그림은 원거리 그림을 줄여 만든다), 깊이 비교 그리기와 비우기, 강아지가 문 나뭇가지 |
| `biome` | 맵 세트: 이름·별칭, 지표 종류·재질별 기본색에서 만든 지형 색, 소품 색, 생성 매개변수, 세트별 색 표, 자동 선택 |
| `species` | 종 정의. 종마다 비트맵·기준점·다리·꼬리·그림자, 걸음 수치(속도·보폭·다리 위상), 뛰기(두 단 호 포함), 오를 수 있는 단 수, 행동 가중치 배율, 처음 기운·들뜸과 기운 변화, 종이 그리지 않는 자세를 바꿀 자세(`poseMap`), 띠 프레임, 품종(종, 뱅크 색, 띠 색 두 벌, 점 비율·줄무늬 간격). 강아지(`dog.ts`, 품종 다섯), 고양이(`cat.ts`, 품종 둘), 거북이(`turtle.ts`), 오리(`duck.ts`), 펭귄(`penguin.ts`) |
| `sprite` | 종 정의로 동물 도트를 그린다(몸통·머리·정면·잠·배 보인 모습은 비트맵, 다리·꼬리는 선), 원거리·맵 보기의 줄인 동물, 감정 표시, 공, 문 공·나뭇가지를 그릴 입 칸 |
| `pet` | 상태, 이동(`motion`), 행동 고르기와 신호 반응(`brain`), 그릴 모습(`pose`), 공, 효과 |
| `scene` | 패널 한 장: 고정 스텝 시뮬레이션, 카메라, 합성(지형, 소품, 강아지 순) |
| `band` | 프롬프트 위 띠의 작은 강아지(쓰지 않음, 늘 꺼짐) |
| `view` | `Raster` 한 장 또는 안내 글 |
